Publique o projeto no servidor seguindo o `docs/publicar.md`:

1. Confira que não há mudança sem commit e que o `main` está no GitHub, com o portão verde.
2. Rode `pnpm publicar` e acompanhe a saída.
3. Confira no fim: o endereço do site abre com o cadeado, `/api/saude` responde e `/api/docs` abre.
4. Se algo der errado, pare, me mostre o erro e proponha como voltar para a versão anterior ("Voltar atrás", no `docs/publicar.md`).
